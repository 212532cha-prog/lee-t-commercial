# 阶段2 — 产品、基础资料、照片与稳定QR

基线：PRD v2.1、开发计划v3.1、REQ-20261101。上一阶段原生PostgreSQL17、Node22/24的51项测试已通过（工作流41294966098）。本阶段不改变已确认业务规则。

## 已实现

- 可校验版本/校验和的事务迁移：新增产品/三类主资料/余额/事件保护基础/任务产品范围/文件清理队列。已应用SQL发生变化时拒绝启动，不静默重算或覆盖。
- 产品初始库存0、非负成本和最低库存、可选照片/多供应商及默认供应商、同名允许但提醒、P000001递增不复用、编号/名称修改不改QR。
- 三标签基础资料：类别/位置/供应商，无计量单位。删除在用类别/供应商保留最新名称和已删除标记；管理员可随后编辑。位置树防环、内置未分配位置不可删、删除父位置将产品移至未分配，子位置子树保留。
- A–Z与稳定次序的游标连续加载、类别/位置组合筛选；无快速搜索/分页。已实现产品列表/详情/同页表单/照片管理、三语基础页面与员工只读数据。
- 真实QR生成/管理员下载打印、员工只读查看、token识别接口；独立jsQR解码器实际验证图像内容，不用文字占位。相同产品token不含IP或名称。
- 实际JPG/PNG解码重编码，输入/输出5MB限制、元数据清理、64MP解码安全上限、受控文件权限；禁止类型伪装/符号链接/路径逃逸。替换/删除/产品删除的文件队列可重试，失败不谎称清完。
- 产品直接永久删除需要确认标记；168小时内任一入库/出库/调整事件以及待接受/进行中盘点范围均阻止删除。当前表关联真实级联清除，无产品回收站/恢复接口；报告/草稿/导出等尚未实现表的级联在后续阶段继续验证，不能宣称已完成全系统级联。

## 发现和修复

A–Z大小写折叠后无明确创建次序，测试发现Beta/beta分页顺序不稳定；新增唯一稳定排序序号并将其纳入游标，未改测试预期。加载更多错误后按钮会保持禁用，修复finally状态渲染并增加回归用例。类别删除后编辑其他资料不应被迫静默改成首个类别，增加保留已删除名称快照的编辑及表单状态。

## 验证

本地使用实际嵌入式PostgreSQL WASM引擎执行SQL/API，不能冒充原生多连接。新增19项SQL/API/文件/QR测试、6项UI单元测试，连同原51项本地实际全量76项通过，失败0、跳过0；生产依赖审计报告0漏洞。CI在各自隔离schema的PostgreSQL17真实服务重跑全部用例，避免测试文件互相清空账号数据。

关键覆盖：并发编号/token唯一、零初始库存、非法值整体无写入、稳定分页/过滤游标、员工API无成本/不可改、QR真实解码、图片安全和清理重试、保护期及任务阻止、168小时边界、其他产品余额不变、迁移变化拒绝。

未完成：真实扫码枪/手机摄像头和浏览器端到端、库存入出库/历史调整业务、盘点任务/报告、完整备份上传恢复、最终Windows安装迁移和全套117验收。界面明确显示尚未实现部分，不把文档定义当作功能完成。
