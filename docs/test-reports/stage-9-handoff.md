# 阶段9交接与Go/No-Go

本版本交付形态是源代码候选包；正式上线结论为NO-GO，原因是目标仓库设备验收尚未执行。不是因为尚未选择最终服务器而暂停工程开发。

候选包由Linux原生PostgreSQL/Node22及24、Windows服务/证书/原生数据库运行三组工程检查全部成功后生成，包含受版本控制的程序、迁移、锁定依赖清单、规格、测试与手册，以及每文件SHA256清单。独立Python读取ZIP核对全部内容。仅源代码，不含生产资料、口令或私钥；运行仍需安装环境和生产依赖。

安装/更新/回退/迁移操作见docs/deployment/install-and-migrate.md。首次产品库存为0，通过实际入库或管理员绝对调整建立数量，盘点报告不能作为自动初始化工具。员工培训需覆盖同码每次+1、−/＋、草稿和断线区别、任务刷新重盘、单设备接管及只报告盘点。

上线前由现场执行并记录：目标Windows预检和服务开机自启/关机重启；两类手机证书/摄像头；真实HID扫码；无外网LAN；弱网盘点失效；真实双盘及双满限制；整包上传到另一环境恢复并对照资料；更新前备份和回退演练。执行117项验收案例中适用的全部步骤，修复失败并重跑关联及全量测试。最后备份并校验，确认只有一台正式写入服务器，再作Go/No-Go。不能用自动测试数量代替这些证据。

代码仍在草稿PR中，没有自动合并、正式发布或向用户电脑部署。业务规则不需重新确认；后续需要用户协助的是实际设备操作与结果。
