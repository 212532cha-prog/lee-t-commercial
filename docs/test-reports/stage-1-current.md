# 阶段1 — 登录与身份基础开发记录

基线：PRD v2.1、开发计划 v3.1，REQ-20261101。

## 执行边界

负责人明确先用当前电脑作为临时局域网服务器，后续换机；工程门槛通过即可继续，不等待固定最终Windows电脑。ADR-004记录门槛时点调整，现场验收全部保留。已进入阶段1基础实现，尚未实现产品/出入库/盘点业务/备份上传迁移，不是全系统完成。

## 实现

- PostgreSQL版本化迁移及单管理员约束；首装受保护口令建立CTL LEE、重启不重置；Argon2id哈希。
- 管理员多设备、员工新登录接管旧设备，数据库会话代际/不存原始登录token；旧会话API立即拒绝。
- 员工新增/编辑/重设/停用，停用保留账号并使未完成任务状态退回待接受；任务数据结构仅为归属守卫预留，发布/计数尚未实现。
- 受保护本机管理员凭证恢复，保留内部ID；无公开注册/邮件恢复。
- 登录页、三语基础页面、管理员员工管理；Secure/HttpOnly/SameSite Cookie、Origin/CSRF检查、登录节流、JSON体积/形状校验。
- 管理员专属备份限制、全员维护、员工盘点占用三类状态守卫分开；实际备份/任务模块尚未实现。
- 所有地址/数据库/秘密外置，loopback后端接HTTPS代理，不把客户端IP写进产品标识。完整包下载/上传迁移已纳入BACKUP-12与后续阶段。

## 测试

本地：Node.js 24；有效测试51项，通过51、失败0、跳过0；含14项SQL/API身份测试。数据库采用PGlite的实际PostgreSQL WASM引擎，并非数组Mock；但它串行化单实例，不能冒充原生PostgreSQL多连接竞争证据。

CI：新增PostgreSQL17独立服务，Node22/24两组强制WAREHOUSE_NATIVE_PG=1，必须数据库名以_test结尾。同一测试集在真实服务重跑；没有数据库时失败，不回退到嵌入式，也不跳过。当前提交时等待CI，以PR实际结果及后续证据为准。

覆盖：管理员两会话与5员工并存、员工并发登录仅一会话、唯一约束、停用和任务归属、密码重设/管理员恢复、Origin/CSRF、Cookie、无注册找回、错误JSON/超大请求、原有TLS/相机控制及规格门槛。新增迁移用例仅为验收定义，未执行真实恢复。
