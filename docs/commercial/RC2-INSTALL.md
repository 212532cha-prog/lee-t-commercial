# LEE T Commercial 0.8.5 RC2

此版本统一 Windows 仓库、Android 管理员与离线库存、本地签发协议和桌面授权客户端的源代码。它是正式发行流程的候选版本。Windows 代码签名、Android 正式发布签名和最终实机验收待完成，安全提示可能仍出现。

## 下载与安装

下载 LEE-T-Commercial-0.8.5-RC2-Windows，解压后运行 LEE-T-Commercial-0.8.5-RC2-Setup.exe。SHA256SUMS.txt 用于核对下载文件。默认程序目录为 C:\Program Files\Lee T Commercial，默认数据目录为 C:\ProgramData\Lee T Commercial。可在向导中选择另一个本地 NTFS 数据目录。

安装器内置配套公钥和签发者编号，使用离线激活窗口。导出设备请求，在原签发电脑的 License Center 选择客户及付款后签发，将签名许可证导入安装器，再继续设置管理员账号和密码。签发私钥由签发电脑保管。

原来已有仓库服务时，使用备份及迁移流程处理旧安装。此候选版对既有服务保留保护检查。新目录不会自动导入旧仓库资料。

## 手机

安装同一候选分支构建的 Android APK。管理员通过仓库身份二维码连接，员工沿用配对流程。管理员离线库存显示上次同步的商品编号、名称、数量及时间，保存访问期限为七天，退出会清除保存访问。

## 卸载与测试重装

在 Windows 已安装的应用中选择 LEE T Commercial 卸载，或运行程序目录里的 unins000.exe。卸载程序停止并移除属于本次安装的仓库服务，关闭该目录的桌面进程后移除程序文件。

默认保留数据。只有在“永久删除仓库数据”的提示中明确选择 Yes，才会删除本次安装记录里的数据目录。该操作永久删除商品、库存、账号和历史。选择完整删除时，也会删除匹配本次安装身份的激活缓存和本机 Windows 用户的仓库桌面登录缓存。重新安装需重新导出请求并签发许可证。选择保留数据时，这些资料保留。

若另一个服务仍引用本安装目录中的程序文件，卸载会显示依赖问题并停止，需要先迁移依赖。License Center 授权账本和签发密钥属于签发后台。

## 当前验收范围

构建通过后，仍需在干净 Windows 完成安装、实际离线签发和导入、开机自启、同版 Android 业务与离线管理员，以及实际卸载和重装验收。License Center 自包含安装和双击自动启动后台仍待开发。正式签名及安全分发要求见任务 #30。

卸载范围为本安装程序管理的程序、服务、所选数据目录及上述缓存。用户另存到外部目录的备份、导出文件、原始安装包和另一台设备上的手机资料需由用户另行管理。
