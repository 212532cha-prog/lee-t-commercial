# 手动库存数量覆盖（2026-11-05，最新用户确认）

范围：管理员在产品详情用键盘输入**非负整数**，二次确认后直接保存当前库存数量。

- 不创建入库、出库、库存调整历史；不记录本次操作的修改前数量、操作者、时间或原因；不写入审计账本。
- 原有入库/出库历史保持不变，后续扫码增减以**最新当前库存**为基准，不从历史全量重算覆盖。
- 仅启用的管理员有权限；员工拒绝。提交使用数据库原子比较版本号防止并发覆盖。
- 盘点仍仅生成报告，不自动修改库存；不改变其他业务事件已有的审计规则。
- 此条针对**管理员手动覆盖库存**，优先于 ADR-002 第 1 条关于所有变更记录审计的旧描述；其他操作继续沿用 ADR-002。
- 风险：手动误改无法通过历史追溯；备份仍必须保留。
