# ADR-003 — 当前业务规则与旧验收迁移

状态：已确认；2026-11-01；基线 REQ-20261101。

当前权威来源：PRD v2.0、开发计划 v3.0、验收清单 v1.0。此决定是负责人多轮明确选择的汇总，不是为通过测试降低标准。

## 替换映射

| 原检查 | 失效原因 | 新验收及保留的保护 |
|---|---|---|
| ADR-001 盘点更新库存并在旧版本冲突时整份拒绝 | 负责人改为盘点只报告、不修改库存 | COUNT-T11～T18：整份报告原子/幂等、提交时快照、不写库存、不改库存版本，取消/接管旧轮次拒绝；入出库并发仍测试 |
| ADR-002 全部九项保持原文不变 | 多轮新决定覆盖历史删除重算、单位、额外副本及邮件恢复 | PRD替换矩阵 + 对应 HIST/PURGE/BACKUP/AUTH 组，编号/负数价值/最近10条/位置迁移继续保留 |
| 删除历史重算 | 负责人要求清理不改当前库存 | HIST-T05～T10：真实删除、168小时、备份先成功、检查点/近期编辑正确，不复活旧明细 |
| 产品回收/30天 | 负责人取消产品回收站 | PURGE-T01～T07：直接永久删除、168小时和任务保护、完整级联，报告回收站保留 |
| 全账号多设备、多管理员 | 1管理员多设备，5员工每人一有效设备 | AUTH-T08～T11：管理员多设备、员工接管/旧请求拒绝、正常续期不误踢 |

保留原测试文件中未冲突的文档、gitignore、LAN、只读Windows预检与真实设备门槛检查。对两项旧语义测试进行有记录的等效更强覆盖替换，新增规格反向校验、实际TLS请求、路径拒绝、凭证扫描故障注入、阶段门槛不能自报通过等测试。后续真实数据库/业务验收均未执行，禁止用本阶段测试冒充。

## 门槛

阶段0仍需真实 GitHub CI、目标Windows、iPhone/Android受信任HTTPS、断外网局域网验证。当前只实现预检服务和工程检查，不进入阶段1数据库/正式登录模块。没有降低真机门槛。
