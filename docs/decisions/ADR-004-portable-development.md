# ADR-004 — 临时服务器开发与完整备份迁移

状态：已确认；2026-11-01；补充PRD v2.1、开发计划v3.1。

负责人明确：先用当前电脑作为临时局域网服务器，后续换其他电脑，不在开发前指定唯一最终主机。工程检查通过后继续阶段1；真实Windows/手机HTTPS/LAN/硬件/异机恢复项目不删除、不假报通过，在最终部署前执行。

测试迁移：原“现场没通过就禁止阶段1”的门槛改成两种明确scope；工程scope必须五项都通过，deployment scope仍包含全部现场项并在缺证据时失败，未知scope拒绝。新增对应反向测试，避免把转移执行时点变成跳过验收。

完整备份支持旧机下载、新机上传和整套恢复；新机须先安装应用/运行环境，并配置路径/IP/HTTPS与服务，不能仅改IP而没有数据。迁移向导/脚本集中配置，旧机最终快照后暂停写入，新机验证后仅一个正式写入服务器。新增4个业务用例，目前未执行，旧113用例保留。
